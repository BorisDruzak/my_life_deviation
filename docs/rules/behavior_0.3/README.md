# Механики НПС: действующая редакция поведения 0.3

BEHAVIOR-0.3 остаётся базой правил. Последующие материалы применяются только
в явно указанных границах: [COG-0.4](../cognition_0.4/README.md) уточняет
когнитивные контракты, а [COMMUNITY-0.10](../community_0.10/README.md)
задаёт профиль поселения. Их наличие не означает, что каждый нормативный
раздел уже исполнен `life_core`.

**Обязательная точка входа:** [BEHAVIOR-0.3 — состав, приоритет и таблица поправок](Редакция_поведения_v0.3.md). Старые файлы сохранены как версионные основания; заменённые правила из них не исполняются повторно. Решения пользователя отделены от предлагаемых для проверки формул и баланса.

## Что из прежних документов остаётся действующим

[SEM-0.1](Предметы_понятия_действия_и_социальные_контракты_v0.1.md) — мир, восприятие, ограниченные понятия, способы, нейтральное исполнение и социальные соглашения. Покупка остаётся обменом; употребление еды не списывает деньги. Полное институциональное исполнение временно выключено профилем МОР-0.2, но реальные договоры и межличностные действия не отключены.

[Внутренняя v0.2](Внутренняя_симуляция_человека_v0.2.md) вместе с сохранёнными в ней разделами [v0.1](Внутренняя_симуляция_человека_v0.1.md) — тело, ощущения, эмоции, внимание, приятность, Q/C/W и глубина знаний. Статус влечения «требует решения» заменён ВНУТР-0.3. Пять старых каналов W сохраняются, шестой добавляется; 16×5=80 заменено на 16×6=96. Глобальные лимиты новых связей не увеличены. Туалет и гигиена исключены; максимум причин эмоции сохранён.

[ОТН-0.1](Отношения_как_часть_модели_НПС_v0.1.md) — направленные личные знания, тематическое доверие, забота, сводки, постепенное наблюдение и стоимость операций; дополнено ОТН-0.2 и БИО-0.1. [МОР-0.1](Мораль_нормы_и_оценка_поступков_v0.1.md) — субъективная квалификация, группировка дублей, вина/стыд и медленное принятие; дополняется МОР-0.2 без второй моральной шкалы.

[Субъективная модель v0.2.1](Обучение_свойства_и_внутренние_расчеты_НПС_v0.2.1.md) и [модель личности v0.1](Модель_личности_и_выбора_действий_v0.1.md) сохраняются как архитектурные основания. Конкретные правила выбираются по таблице BEHAVIOR-0.3, а не по самому большому номеру файла другой подсистемы.

[SAFE-OPT-0.1](../Оптимизация/Семантически_точная_оптимизация_v0.1.md) остаётся нормативным контрактом точности. [SEM-PERF-0.1](../Оптимизация/Производительность_семантического_контура_v0.1.md) и [оптимизация UE5 v0.1](../Оптимизация/Оптимизация_симуляции_и_UE5_v0.1.md) читаются с OPT-0.3. Расчётные числа не являются замерами. Отключение институтов — профиль симуляции, не «та же модель быстрее».
