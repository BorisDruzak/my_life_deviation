# Коэффициенты и настройки WORLD-0.5

`data/parameters.json` — профиль правил; `data/catalog.json` — физические типы/рецепты и документация контрактов. **Это не язык программирования:** добавление имени действия в JSON не создаёт его обработчик. Изменение файлов меняет конфигурационный SHA-256 и делает старые снимки несовместимыми. Для продолжения старого прогона нужен исходный каталог.

## Активные параметры

| Раздел | Как используется |
|---|---|
| `needs.N01..N05` | Скорости/пороги копируются в индивидуальный `Need` при создании; конкретный NPC может переопределить их в сценарии. При восстановлении берутся сохранённые индивидуальные значения, а не новые defaults. |
| `traits`, `norm_prices` | Начальные свойства акторов; исполнитель не «заставляет» их действовать. Экспериментальная политика использует поддержанное подмножество свойств, а не все цены из WORLD-0.3. |
| `profiles` | Включение N05 через профиль/состояние, обучения навыкам/интересам, переменной скорости, дополнительного стресса потребностей. |
| `physical` | Нагрузки и восстановление, физические границы, скорость, угасание боли/нарушения состояния. `carry_capacity_kg` — значение при создании NPC. |
| `repetition` | Постоянная затухания и экспозиция в минутах; непрерывное занятие не получает бонуса от дробления. |
| `learning` | Скорости и положительная оценка успешного занятия в extended. Отрицательные обучающие эпизоды этой версией не порождаются. |
| `drive` | Рост давления и облегчение успешного присвоения; интенсивность постоянна в этом эксперименте. |
| `emotions` | Затухание, спокойный отдых и возвращение самооценки к базовой. Успех ремонта учитывается отдельно. |
| `relationships` | Насыщение от общения, прирост привязанности, снижение напряжения, одноразовые социальные оценки и cooldown пары. |
| `money.wellbeing_half_life_minutes` | Скользящее значение денежного положения за игровое время. |
| `perception.attention_base`, `perfect_observation` | Default внимания и отключение случайного пропуска уже геометрически доступного наблюдения. Не дают видимость сквозь закрытый ящик и сон. |
| `stimuli.own_promise_breach`, `other_promise_breach`, `new_demand_episode` | Реакции на известные субъекту нарушения/требования с однократностью причин. |
| `intimacy.*_total_gain` | Абстрактные эффекты optional extended для взрослых, без автономного инициирования политикой. |
| Пары `thresholds.*.on/off` | Гистерезис сигналов и допустимости тяжёлой нагрузки. Сигнал сам не является решением. |

## Зафиксированные в C++ соглашения

Часть исходных коэффициентов сохранена в JSON для сопоставления со спецификацией, но в WORLD-0.5 является **описанием фиксированной политики, а не настраиваемым переключателем**. Не меняйте следующие значения, ожидая автоматического изменения механики; изменение требует изменения C++ и регрессионного теста:

- Шаг 1 минута, сутки 1440 минут, знаменатель оплаты 60. Отличающиеся значения этих трёх полей явно отвергаются загрузчиком.
- `time.numeric_tolerance`: в конкретных инвариантах используются локальные допуски; единого глобального регулятора точности нет.
- `needs.*.enabled_baseline`: по умолчанию N01–N04 присутствуют, N05 требует extended и явного допустимого состояния; отдельные метаданные не переписывают сохранённые Need.
- `thresholds.established_belief = 0.75`: простая трёхзначная классификация 0.75/0.25; `beliefs.default_prior = 0.5` и `root_merge` описывают фиксированный консервативный оператор.
- `perception.impairment_factor/pain_factor = 0.5`, `channel_free = 1`, `channel_busy = 0.5`, `channel_sleep = 0`: эти коэффициенты заданы в `World::emit`. `partial_visibility` не реализует дополнительную геометрию полупрозрачных препятствий.
- `beliefs.half_life_minutes`: справочные рекомендуемые значения; у конкретного `Evidence` есть собственные `half_life` и `prior`. Они сохраняются в снимке. Нет автоматической классификации любого произвольного высказывания по этим трём названиям.
- `intimacy.minimum_age = 18`, `private_minutes = 10`: обязательная граница взрослых и фиксированный контракт A31 в коде. Длительность совместной активности задаётся согласованными terms, не общим `mutual_minutes`.
- `drive.intensity_policy = fixed`: естественный дрейф интенсивности пока отсутствует.

## Сохранено как направление следующей версии, не включено

`learning.valence_unpleasant`, `relationships.romantic_growth_per_hour`, `stimuli.important_item_loss` и отдельное `emotions.selfesteem_failure_delta` не порождают автоматические события/изменения. Например, мир не узнаёт за NPC о скрытой пропаже важной вещи. Общая реакция на неудачу не вызывается за любой отвергнутой командой, иначе при переборе вариантов можно было бы менять эмоции.

Значения таких полей присутствуют в конфигурационном отпечатке, но не считаются доказательством реализации механики. Удаление/подключение поля в следующей версии оформляйте как изменение контракта.

## Предметы и рецепты

Параметры экземпляров (`owner`, размещение, остаток порции, состояние, содержимое) хранятся в `State`, а физические свойства типа — в каталоге. Длительности рецептов и используемые свойства проверяются исполнителем; произвольный новый эффект в JSON не исполняется без обработчика. Списки `actions` и `events` документируют действующую библиотеку, а не добавляют динамический код.

## Валидация не заменяет тестирование нового баланса

Загрузчик проверяет версию, базовые диапазоны, положительность знаменателей, гистерезис и ссылки, но не доказывает пригодность всех сочетаний коэффициентов. При изменении профиля выполните весь набор тестов, длительный прогон и отдельные контрфактические опыты. Аргумент «это же только JSON» не освобождает от проверки правил.
