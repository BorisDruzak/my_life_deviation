# COG-0.4: когнитивные правила

COG-0.4 расширяет BEHAVIOR-0.3 субъективными оценками, вниманием, нормами,
проектами и правилами разделения игрового и вычислительного времени.

- [Когнитивный контур](Когнитивный_контур_v0.4.md) — нормативный контракт.
- [Поправки COG](Поправки_COG_v0.4.md) — порядок применения к прежним версиям.
- [Планировщик](../../architecture/cognition_0.4/Планировщик_когнитивных_задач_v0.4.md) — planned архитектурный контракт.
- [Исполняемый reference](../../../reference/cognition_0.4/README.md) — локальные C++20 контракты, не полная интеграция мира.

COG reference проверяет отдельные формулы и детерминированную очередь. Он не
является доказательством полной реализации COG в `life_core`.
