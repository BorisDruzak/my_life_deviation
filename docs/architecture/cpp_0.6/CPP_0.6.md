# C++ 0.6.0-lab1: автономный исполнитель

**Статус:** работающий ограниченный лабораторный профиль, не полная реализация BEHAVIOR-0.3.
Спецификации — [редакция поведения](../Документация/Механики/Редакция_поведения_v0.3.md).
Результаты — [отдельный отчёт](../reports/CPP_0.6_validation.md).

## Сборка и запуск

C++20, CMake, стандартная библиотека C++; сеть, LLM, Python и Unreal для самого
исполнителя не требуются. Фактически проверены GCC 14.2 и Clang 17 в Linux.
Windows/MSVC в этой среде не проверялись. Численные параметры — игровой баланс.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
(cd build && ctest --output-on-failure)
./build/mld_sim --npcs 128 --seed 42 --days 7 --out week.json
./build/mld_sim --npcs 16 --temptation --norm 0 --days 1 --trace events.csv
./build/mld_sim --npcs 16 --temptation --norm 1 --days 1
./build/mld_sim --npcs 16 --scarce --days 2
./build/mld_sim --npcs 16 --seconds 371 --save state.snapshot
./build/mld_sim --load state.snapshot --days 1 --save continued.snapshot
python3 tools/run_experiments.py --binary build/mld_sim
```

`--reference` включает полный поиск вместо индексов при тех же правилах и времени.
`--dump-npcs actors.csv` сохраняет конечные шкалы/места/действия каждого НПС.
Длительность одного запуска 0–31 суток; 8–1024 активных взрослых, чётное число.
Snapshot содержит собственную конфигурацию; `--load` запрещает подменять её флагами.
Трасса — технический журнал, не сведения, автоматически известные персонажам.
В `talk` считаются завершения взаимодействия участниками, не уникальные разговоры.
`failures` — отказы и несостоявшиеся игровые попытки, не число программных аварий.

## Мир и контент лаборатории

Звездообразный граф: перекрёсток, магазин, вода, общественное место, работа и
домохозяйства по два жителя. Каждое ребро проходится за 120 секунд; переход через
перекрёсток сохраняет намерение. На рёбрах нет встреч/наблюдений в этом профиле.

Есть конечные запасы, проверяемый обмен, употребление еды без списания денег,
взятие без разрешения, питьё, сон с латентностью 120 секунд, отдых, досуг, запрос
общения/отдельный ответ, абстрактное индивидуальное удовлетворение влечения и работа.
Give зарезервирован, выключен в каталогах и не реализован. Совместный сексуальный
контакт не реализован. Все активные персонажи — взрослые; внешние предки — записи.

Обычный профиль получает ежедневную явную внешнюю поставку еды/воды. Зарплата —
явный внешний источник денег. Это не замкнутая экономика производства.
`--scarce` убирает поставку еды и уменьшает стартовый запас: это намеренно
необеспеченный мир, не проверка способности добыть несуществующие ресурсы.
`--temptation` задаёт голод, отсутствие личной еды/денег и доступный магазин:
он создаёт возможность нарушения, но не назначает действия. Меняется только
конфигурация стартового мира; все НПС используют один контроллер.

Цена санкции субъективна, фактических штрафов нет. Персонажи знают из начального
содержания общественный граф и расписание поставки магазина. Пустой домашний
источник не инспектируется заново без основания ожидать изменения. Исчезновение
скрытого запаса не исправляет память до наблюдения. Нет механизма биологической
смерти: повреждение достигает 1, но запись НПС не удаляется.

## Архитектура и точные ускорения

`internal` — численные переходы; `generation` — посев/валидаторы; `controller` —
личный View; `world` — авторитетный исполнитель; `storage` — канонический снимок;
`hash` — SHA-256 и адресные выборки. Старый orphan `src/persistence.cpp` сохранён,
но не входит в библиотеку: новый snapshot имеет собственную схему.

View не содержит World, скрытых запасов, чужих коэффициентов или матрицы W.
Психические/телесные воздействия вычисляются отдельно от субъективного выбора.
Один физический шаг = 1 игровая секунда; обзор решения = 30 секунд/событие.
Это явный опорный профиль, не оптимизированное укрупнение старого полного ядра.

Общие каталоги/ID, компактное состояние, разреженные W, не более 96 адресных
обращений к парам W за обновление, индекс присутствия и очередь due-событий.
Равенства разрешаются стабильно; отдельная адресная случайность для событий.
Один поток. Нет fast-math, SIMD-приближений, скрытого LOD или адаптации качества
к загрузке CPU. Физика всех активных НПС выполняется одинаково. Кэши поиска
восстанавливаются и не являются частью первичной истории.

Снимок: поля фиксированного порядка, big-endian числа, IEEE-754 double, SHA-256
полезной нагрузки, версия профиля и каталога. Сохраняются текущие действия,
прогресс сна, намерение, память, Q/W, таймеры, запасы и счётчики. Нет миграции
исторических C++-сохранений. Порядок потоков не тестировался: параллельности нет.

Биографические связи частично инициализируются как стартовые предположения,
а не все вычисляются из полного жизненного воспроизведения. Склонности могут
проявляться через выбор, но естественное приобретение девиаций ещё не доказано.
Все эти ограничения принадлежат лабораторному профилю; нормативные спецификации
не переопределены скрыто под фактически написанный код.
