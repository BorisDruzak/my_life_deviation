# RECOVERY-0.13: план восстановления функциональности

**Основа:** исходники архива SELF01 0.12, SHA-256 b038460398aa82fd8652b820718b721e2b73dfa4d5b979b3e770a75061b37c4a.
**Цель:** восстановить согласованные дополнения без удаления SelfModel, карьеры и пауз проектов.
**Архитектура:** факты мира → восприятие/сообщение → ограниченная личная память → оплаченная переоценка → атомарное действие. Новые функции включаются профилем `--recovery`; прежние режимы сохраняются для регрессии.
**Стек:** имеющийся C++20, CMake, стандартная библиотека; без новых внешних зависимостей.

## Ограничения
- Статус не является общим числом. Доход, видимая одежда, траты и гипотеза о способности помочь хранятся раздельно.
- Executor не изменяет SelfModel. Только OutcomeSignal и существующая интерпретация.
- Обмен сохраняет деньги/товары; запас пополняется явной внешней поставкой, не reset.
- Новое сообщение/инструкция не является опытом исполнения. Неизвестный шаг остаётся неизвестным.
- Телефон собственный предмет; известный номер; send/deliver/read разделены. Непрочитанное сообщение не меняет чужой план.
- Миграция старых binary save не выполняется; новая версия явно отвергает старые.

## R1. Типизированные сведения и общие вопросы
Файлы: include/life/resources.hpp, src/life/resources.cpp, tests/test_resources.cpp.
Тесты: дубликат корневого основания; зарплата не изменяется от обычных покупок; вещь не доказывает наличные/собственность; неизвестность; частичные сообщения; ограниченный размер; новый факт будит связанный вопрос, повтор не будит.

## R2. Одежда, магазин, бюджет
Файлы: include/life/civil.hpp, src/life/civil.cpp, src/life/civil_world.cpp; интеграция mind/world/executor.
Тесты: зависимость износа от времени; запас и деньги при конкуренции; требуется действующий сотрудник; закрытие/отмена; разные выбранные цели меняют резерв; мысль о покупке не меняет SelfModel.

## R3. Денежная помощь и обучение процедурам
Файлы: src/life/civil_social_world.cpp; расширения social и projects; tests/test_civil_social.cpp.
Тесты: отдельное решение получателя; деньги не создаются; прерывание не переводит сумму; известная последовательность передаётся без фиктивных successes/Q/W; отсутствующий атомарный навык блокирует применение; применение идёт обычным ProjectMemory.

## R4. Телефон
Файлы: src/life/phone_world.cpp, tests/test_phone.cpp.
Тесты: нет номера/предмета — нет отправки; запрос номера; доставка не чтение; повтор не даёт результата; текст совместим с работой и несовместим со сном; отмена встречи только после прочтения; сохранение в процессе отправки/доставки.

## R5. Сквозные проверки
Новые сценарии плюс полный Release CTest, SelfModel, ASan/UBSan (явный список исключённых длинных заданий), workers/reference/save-restore, свободные дефицитные миры на нескольких seed. Проверить патч `git apply --check` на чистой базе и совпадение файлов результата.

## Последовательность исполнения
Для каждого R: сначала тесты и зарегистрированный отказ, затем реализация, повторный запуск и локальный коммит. Проверки пакета содержат команды, коды выхода, хеш исходников/бинарника. Неудачные эксперименты не заменяются поздними числами.
