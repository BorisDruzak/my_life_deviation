## Как запустить

```bash
./build/npc_tests --list
./build/npc_tests --case S05_joint_requires_both_commands
ctest --test-dir build --output-on-failure
```

CTest `core` запускает все native-проверки; `cli` — Python-интеграцию с реальными файлами и процессами. При отсутствии Python второй CTest не регистрируется, но C++-ядро и native-проверки продолжают собираться.

Дополнительные регрессии R*/проверки C* перечислены самим тестовым executable. Sanitizers и недельный прогон являются отдельными проверками и не превращаются в фиктивные сотни тестов.
