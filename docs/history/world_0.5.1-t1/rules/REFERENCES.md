# Использованные первичные технические источники

Источники описывают инструменты и известные подходы, а не подтверждают игровой баланс наших коэффициентов.

- CMake/CTest: https://cmake.org/cmake/help/latest/manual/ctest.1.html
- AddressSanitizer (Clang): https://clang.llvm.org/docs/AddressSanitizer.html
- UndefinedBehaviorSanitizer: https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html
- Boost.JSON: https://www.boost.org/doc/libs/1_83_0/libs/json/doc/html/index.html
- Boost Software License 1.0: https://www.boost.org/LICENSE_1_0.txt
- SHOP, иерархическое планирование: https://www.cs.umd.edu/projects/shop/description.html
- Частичная наблюдаемость: https://people.csail.mit.edu/lpk/papers/aij98-pomdp.pdf

Boost.JSON хранится локально в `third_party`; сетевого получения зависимостей при сборке нет.
