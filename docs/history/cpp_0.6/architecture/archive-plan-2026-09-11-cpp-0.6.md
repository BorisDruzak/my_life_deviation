# C++ 0.6.0-lab1: план реализации

Цель: собираемый автономный стенд по BEHAVIOR-0.3, без выдачи сокращённого
контента и непокрытых подсистем за полное исполнение всех спецификаций.
База main: fa3aec539055cafdf520d558b0e97537dcf9435b.

Архитектура: C++20, числовые ID, отдельные субъективный контроллер и физический
исполнитель, опорный физический шаг 1 с; решения на событиях/30-секундном обзоре.
Сборка CMake, без сторонних библиотек C++. Существующий orphan persistence.cpp
остаётся историческим и не включается в новую библиотеку mld.

1. Численный слой: tests/unit.cpp сначала проверяет нулевое время, недопустимые
   входы, тело, D/R/V, Q/W, мораль, зависимости и ограниченный вывод.
   Затем include/mld/internal.hpp и src/mld/internal.cpp реализуют контракты.
   Команда: cmake --build build && ctest --test-dir build --output-on-failure.
2. Посев: tests/world_tests.cpp проверяет 100 seed, родство, связность,
   известные источники; src/mld/generation.cpp создаёт историю и начальное состояние.
3. Замкнутый мир: контроллер принимает только View, не World. Взять/обменять,
   употребить, пить, двигаться, спать, отдыхать, общаться и досуг имеют отдельные
   длительности/проверки. Институты не штрафуют. Тесты пустого источника,
   последней порции, скрытого состояния, завершения/прерывания.
4. Точное ускорение: индекс событий/локальности и опорный полный поиск на том
   же логическом шаге. Тесты совпадения состояния и журнала. Никакого fast-math.
5. Снимок: полное состояние, версия и checksum; отказ на несовместимости,
   повреждении/недостающем поле; roundtrip и непрерывное/возобновлённое исполнение.
6. Прогоны: малый мир, 128 НПС на 7 суток/несколько seed, ресурсный стресс,
   paired-контроль нормы. GCC Release, Debug ASan/UBSan, второй компилятор при наличии.
7. Зафиксировать reports/*.json и отдельную матрицу соответствия: полный,
   частичный, только unit, отсутствует. Публиковать код только с проверенными SHA.

Критические ограничения: одинаковые правила всех активных НПС; нет LLM;
ожидаемая санкция не списывает средства; впечатление не равно истине;
приобретённая приятность не является первичным подкреплением самой себя;
тесты формул не заменяют интеграционные сценарии; данные баланса версионированы.

## Фактический итог

Собираемый стенд, численные проверки, 100 посевов, недельный прогон, контроль
нормы/ресурсного стресса, snapshot/differential и три сборки выполнены.
Непокрытые части не считаются закрытыми пунктами: см. docs/CPP_0.6.md и
reports/CPP_0.6_validation.md. Генерация — ограниченная взрослая родословная,
а не весь БИО; отдельные численные helpers не означают интеграции причин,
утраты, репутации и всех норм в мир.
