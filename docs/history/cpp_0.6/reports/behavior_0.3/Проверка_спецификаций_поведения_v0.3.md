# Проверка спецификаций поведения 0.3

**Дата:** 2026-09-11. **Комплект:** BEHAVIOR-0.3. **База:** `0e54c3c81701dd69c0787b3eb4acc121b6a5583e`.

## Что подготовлено

Семь новых нормативных документов, тестовый JSON-профиль, локальный Python-проверочный скрипт и обновлённые README репозитория/механик. Изменения действующих правил оформлены таблицей замен в [редакции 0.3](../Механики/Редакция_поведения_v0.3.md); исторические версионные тела документов сохранены. C++-исходники не изменялись.

Предыстория определена как воспроизводимая генерация с контролем родства, хронологии, происхождения знаний, степеней знакомств и связности. Добавлены зависимость/утрата, накопительный дефицит и триггеры влечения, конечная цена табу, профиль ожидаемых санкций без исполнения, локальная репутация, уточнение процедур и общих бюджетов.

## Исправленные при согласовании неоднозначности

1. «Пять каналов» и предел 80 пар конфликтовали бы с новым влечением: в новой редакции шесть каналов и 96 пар; четыре новые пары и общий предел 512 сохранены.
2. Неизвестная заменимость не считается нулевой: частичная зависимость возвращается с покрытием и статусом, без бесплатной подстановки альтернатив.
3. Исключён автоматический аварийный обход внимания от V≥0,85: порог опасного телесного сигнала не переносится на любое сильное побуждение.
4. Отключённый институт не является отрицательным наблюдаемым исходом и не обнуляет ожидание санкции из пустого журнала.
5. Скрытый корень слуха не используется как правильное знание о зависимости разных свидетельств.
6. При отказе rejection sampling изменяется retry_index, а не номер следующей логической выборки: соседние выборки не переиспользуют один ключ.
7. Совместное взаимодействие не подменяет ответ другого участника; в каталоге есть индивидуальный способ удовлетворения, чтобы потребность не требовала гарантированного согласия партнёра.
8. D/R имеют точные переходы между границами, но это не доказательство точного крупного шага всей связанной системы V/ощущений.

Это исправления спецификации и локальных эталонов, не ошибки, обнаруженные в запущенном C++-мире.

## Фактически запущенные проверки

| Проверочный скрипт | Результат | Что подтверждает |
|---|---:|---|
| `Проверка_редакции_поведения_v0.3.py` | 40 тестов, 0 ошибок, exit 0 | Новые локальные формулы и частные контракты |
| `Проверка_уточнений_внутренней_симуляции_v0.2.py` | 49 тестов, exit 0 | Сохраняемые локальные формулы v0.2 |
| `Проверка_отношений_и_морали_v0.1.py` | 38 проверок, exit 0 | Сохраняемые примеры отношений и морали |
| `Проверка_формул_внутренней_симуляции.py` | 27 тестов, exit 0 | Исторические формулы; не новая полная модель |

Новый скрипт включает 2000 детерминированных случайных наборов для проверки диапазонов; они входят в один из 40 unittest-тестов, не объявляются 2000 отдельными сценариями. Проверяются накопление/насыщение, нулевое время, повтор события, триггер, постоянная цель, неполные данные зависимости, конечная моральная цена, ожидаемая санкция, медленная переоценка, стабильные ключи seed, нормализация Unicode и частные валидаторы графа/родительских связей.

Валидатор знакомств использует небольшие подготовленные графы, а не полный алгоритм генерации биографии. Проверка родительских интервалов работает с годами в фикстуре; настоящий генератор обязан использовать точные даты и остальные ограничения БИО-0.1. Проверка профиля «нет фактического исполнения» удостоверяет настройку, не отсутствие ошибочного штрафования в ещё не созданном C++.

## Воспроизведение

Из корня репозитория:

```sh
python "Документация/Проверки/Проверка_редакции_поведения_v0.3.py"
python "Документация/Проверки/Проверка_уточнений_внутренней_симуляции_v0.2.py"
python "Документация/Проверки/Проверка_отношений_и_морали_v0.1.py"
python "Документация/Проверки/Проверка_формул_внутренней_симуляции.py"
```

Используется стандартная библиотека Python, никаких LLM/сети. Новый скрипт требует Python 3.10+; соседний JSON-профиль нужен для двух проверок конфигурации. Сырые журналы приложены к выдаваемому архиву документации.

## Что НЕ было проверено

Семь документов содержат 72 **будущих** приёмочных сценария по новым контрактам. Они не выполнены как интеграционные тесты: полный seed-генератор, 100 миров, автономное проживание недели, приобретение девиаций, точность оптимизаций C++/потоков, восстановление C++-сохранения и UE5 не запускались. Полные институты осознанно не входят в первый профиль.

Прохождение локальных формул не доказывает физиологическую достоверность, баланс дефицита, реализм общества или экономию CPU. Для следующего этапа требуется взаимодействующий эталонный мир и сопоставление каждой приёмки с реальным тестом, логом и версией исходников.
