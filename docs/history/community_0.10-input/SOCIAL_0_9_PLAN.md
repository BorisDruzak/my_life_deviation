# Социально-предметная интеграция 0.9

Основание: исходный архив 0.8.0 + COG-0.4 + прямое поручение пользователя.
Цель: проверять знания и отношение к способам/предметам, нормы, личные предпочтения,
вложенные взаимодействия и последствия, а не только питание и сон.

## Архитектура
Знакомые социальные способы выбирает тот же Interpret/Recall/Forecast/Compare/Commit.
Предложение внутри Talk не отменяет разговор. Получатель выполняет отдельную
оплачиваемую SocialReply в общем бюджете; явное согласие действительно только для
конкретных участников, формы контакта, предмета и родительского события.
Затем объективный исполнитель перепроверяет условия и выполняет ограниченное действие.
Предсказание не даёт эффекта; последствия приходят участникам в отдельную очередь
Observed -> оплачиваемая SocialObserve -> адресная память/Q и знакомые правила.

## Ограничения
Все активные персонажи совершеннолетние; физический контакт представлен неэротическим объятием.
Дружеское/романтическое, знание/приятность/собственная норма/чужой ответ раздельны.
Предпочтение пола и личная норма задаются конкретному персонажу, не всем людям.
Принятие нормы — конечная цена, не физический запрет; отсутствие согласия другого
не подставляется как согласие и не преодолевается ростом числа запросов.
Общий свободный язык, произвольные договоры и ошибки идентификации не заявляются.

## Файлы и проверки
- [x] `social.hpp`, `social.cpp`: типизированные знания, контекстная память,
  известные условия, отдельная внутренняя реакция, конечные нормы и оценка.
  Проверки: знания без личного опыта; приятность без одобрения; добровольность;
  отдельные дружеские/романтические ожидания; физический пол не является общим запретом.
- [x] `social_world.cpp`: предложения, независимый ответ, отложенное исполнение,
  наблюдения, предметы/заём/возврат/чтение и обучение содержанию.
  Проверки: отказ не даёт объятия; отзыв до эффекта; отмена разговора; сохранение
  посередине операции/согласия; неизвестный собственник не раскрывается.
- [x] `mind.cpp`, `cognitive_world.cpp`: кандидаты с адресатами и предметами,
  сообщения и субъективные причины, реальные ссылки в мыслях.
  Проверки: неизвестный способ не рассматривается; сравнение адресатов;
  получение информации без социального голода; чтение/использование/возврат.
- [x] `generation`, `persistence`, `validation`, `CLI`: версия 0.9, взрослый посев
  с разными знаниями и предметами; разные личные нормы в контрольных фикстурах, сериализация/инварианты.
- [x] `social_scenarios`: парные контрфактические миры + автономная сцена;
  логи двух сторон и точные изменения памяти; 1/4 потока, индекс/reference,
  журнал вкл/выкл, save/load, новые и старые тесты, ASan/UBSan, проверка ZIP.

assert наличие `social_` в result/мыслях. Затем сохранить лог падения и подключить реализацию.
