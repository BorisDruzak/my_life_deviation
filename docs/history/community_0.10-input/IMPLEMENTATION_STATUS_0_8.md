# C++ 0.8.0 — когнитивная интеграция: точная матрица

Дата: 2026-09-11. Источники: архив мира 0.7.0 и COG-0.4. Это исследовательский профиль `balance-cpp-0.8.0-cog04-1`, не полная реализация всех требований COG/SEM.
Историческая матрица 0.7 сохранена в `IMPLEMENTATION_STATUS_0_7.md`.

## Подключено к населённому миру

| Механизм | Реальная работа / граница |
|---|---|
| Последовательные операции | Interpret → Recall → Forecast → Compare → Commit; дополнительные Recognize и Reply. Начало, прогресс, due, источник и версии сохраняются |
| Модельное время | Целые мс. 2+6×Speed операций/с, бюджет 4+floor(28×Speed). CPU не определяет игровую длительность. Пустое время и сон не копят кредит |
| Фокус | Общая ограниченная очередь до 32, гистерезис и минимальное удержание COG, время перестройки; изменение фокуса само по себе не отменяет путь |
| Источники внимания | Внутренние сигналы, обнаруженные люди, ограниченная память о неприятных контактах, известная цель дохода и полученные ответы. Тип Thought есть, но произвольное превращение каждого вывода в конкурирующую тему ещё не реализовано |
| Контекст | Реальные элементы фокуса/оценки/способа/прогноза; ограничение 2..12, в выполненных сценариях максимум 4. Знакомые процедуры компактные. Это не общий распределитель операндов произвольного логического графа |
| Субъективная оценка | Использует сохранённые S/Y и COG fusion, качество и отдельные исходные priors. Unknown и Conflicting не заменяются подтверждённым средним. Старый posterior не копируется как независимый источник |
| Правила интерпретации | По теме требуется усвоение >=.60; тестовые правила 100..108 заранее известны. Неусвоенное правило даёт вопрос, не готовую оценку |
| Физические процессы | Сохранены тело/эмоции/потребности мира 0.7; максимальный шаг 1 с с дополнительными границами для затронутых акторов. Расходы и результаты учитываются по длительности, не числу вызовов |
| Чистый прогноз | Получает копию PersonalView без World*, один известный способ; результат появляется только после due. Версии изменившихся собственных входов делают результат Stale без возврата бюджета |
| Ценность | Использует COG Ledger/дисконтирование/squash; отрицательные ожидаемые эффекты сохранены. Деньги, нормы, риск и время не суммируются вторым штрафом поверх того же эффекта |
| Учёт денег и еды | Как в 0.7: приобретение и употребление разделены, прогноз не меняет запасы; физический ledger сохраняет ресурсы |
| Контакт | Реальный ответ поступает в очередь; отдельная оплаченная Reply-операция. Согласие меняет ожидание доступности, не выдаёт награду за будущий разговор. Отказ имеет ограниченную субъективную интерпретацию и отрицательный опыт |
| Сохранение | Формат LIFE-0.8.0, включая контекст, незавершённую работу, снимок, эпизод, источники, очереди, сообщения, личные оценки; файлы 0.7 отвергаются, миграции нет |
| CPU | Постоянный пул только для независимых прогнозов. Стабильный commit после готовности обязательного batch; physique/executor и остальная когнитивная работа последовательны |
| Диагностика | JSONL создаётся из реально завершённых операций; русский текст — детерминированный шаблон, не LLM и не второе управление поведением. Логирование не меняет IDs/RNG/состояние |

## Явные ограничения относительно COG-0.4

1. **Сенсорный профиль всё ещё дискретный.** Экспозиции собираются на физических границах 1 с. Их hazard и работа признака учитываются, но обнаружение не планируется точно до миллисекунды пересечения. Это не полная точная реализация §5.3.
2. **Узнавание частичное.** До обнаружения/наблюдения и оплаченной операции личность не передаётся планировщику. После накопления признака используется точный шаблон. Конкурирующие ошибочные идентификации отсутствуют.
3. **Интерпретатор правил не общий.** Малый каталог известных процедур компилируется в C++; произвольные SEM-предикаты, комбинации и автономные причинные вопросы не добавлены. C остаётся изолированным модулем из 0.7.
4. **Модель рабочего контекста ещё ограничена.** Компактная процедура включает известный маршрут и прогноз в одной операции; это не разрешение делать так для произвольного нового плана. Контекстный коэффициент ощущения f=.25 не подключён отдельно: сейчас основной фокус даёт 1, периферия 0. Численная формула f=.25 остаётся в эталоне.
5. **Проекты частичные.** Есть известное продолжение «работа→доход→еда», актуальная ценность, сохранённая цель дохода и маркеры паузы/возврата. Нет универсальных четырёх продолжений, стройки, календарной месячной зарплаты и оценки всех будущих состояний. В обычных прогонах pause/resume не возникали. Нельзя выдавать их за успешно проверенную стройку.
6. **Отказы — ограниченный адаптер.** Busy и Declined — фиксированные формы доступного ответа, коэффициенты оценки и rejection_bias заданы тестовым профилем. Приписывание намеренного унижения, публичность, контекст темы, сложные причины, полноценное давление на получателя и переоценка чужого намерения не реализованы. Старое ограничение retry на уровне места остаётся; next_opportunity хранится, но ещё не универсальное условие повторного обращения.
7. **Нормы/репутация не объявляются полными.** Конечная оценочная цена и узкий профиль чувств/контактов работают; универсального морального интерпретатора, слухов и изменения культурных норм нет. Фактические институты отключены согласно решению пользователя.
8. **Неограниченная память не решена.** Очередь внимания и рабочий контекст ограничены, но processed-ID/биографические записи требуют cold storage. Произвольное удаление ключей не применяется. Общая повторная доставка давно обработанного социального сообщения ещё не покрыта как полноценный сетевой протокол.
9. **Физическое состояние при произвольном внешнем stop может быть ленивым.** `physical_at` хранит последнюю границу; до получения следующего авторитетного результата затронутый актор продвигается к now. Произвольный конец API-вызова не создаёт новую мысль/сенсорное наблюдение и не меняет интеграционный путь. Клиент не должен считать всё тело пересчитанным в now без учёта physical_at.
10. **Оптимизация не завершена.** Индекс, подготовленные W и пул сохраняют результат внутри нового профиля. Глобальное сканирование границ и частые копии PersonalView остаются; сокращать физику/содержание мыслей ради CPU нельзя. Эквивалентность 0.7 и 0.8 не заявляется: модель изменилась.

## Соответствие приёмкам COG-I01–I16

| Приёмка | Статус этой выдачи |
|---|---|
| I01 | Проверены скрытый удалённый запас и чужая частная характеристика: собственные мысли не меняются до доступного результата; не доказательство всех возможных проекций |
| I02 | Проверены численное fusion и разные интерпретации одного Busy; общего каталога ошибочных объяснений нет |
| I03–I04 | Численные эталоны норм/исключений сохранены; весь социальный сценарий не интегрирован |
| I05 | Проверен отбор 32 из 60 кандидатов, ограничения контекста; не полный семантический разбор 40 различных объектов |
| I06 | Проверены время начальной перестройки/работы, сон, пределы и правила эталона; сложные последовательности разных аварий требуют расширения |
| I07 | Отдельно проверены сохранение движения при смене фокуса и протокол ответа; не полный естественный диалог во время ходьбы |
| I08 | Реальный короткий сценарий работы ради еды + месячный численный эталон; не месячная экономика |
| I09–I10 | Строительство/альтернативное жильё не реализованы |
| I11 | Прогноз не создаёт выполненное действие/выплату/отказ и новое обучение; вся эмоциональная динамика фантазирования не подключена |
| I12 | Проверена однократность Episode и реально доставленного ответа в текущем протоколе; произвольная история повторов требует расширения |
| I13 | Сравнены полные состояния и мысли при 1/2/4workers, порциях 1/2/17 и разбиении wall-кадров 30/144 в целых мс |
| I14 | Собственная новая версия до commit отбрасывает старый результат; нет возврата операции |
| I15 | Файл в середине мысли восстанавливает то же будущее; не проверка стройки в паузе |
| I16 | Не закрыта: долговременный cold storage отсутствует |

## Файлы реализации

`include/life/cognition.hpp` — сериализуемые состояния. `src/life/cognition.cpp` — субъективные оценки, отбор, журнал. `src/life/cognitive_world.cpp` — подключённый автомат. `src/life/worker.cpp` — пул. `src/life/world.cpp` — физические и логические границы. `tests/test_cognition.cpp` — новые случаи. `tools/cognitive_scenarios.cpp` — воспроизводимые контролируемые ситуации.

Диагностические поля destination/costs у Thought не являются источником решения и не входят в save: после загрузки новые записи получают их из нового завершённого расчёта; старые строки журнала не воспроизводятся заново.
