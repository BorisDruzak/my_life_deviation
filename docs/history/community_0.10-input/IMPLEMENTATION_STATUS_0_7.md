# C++ CORE 0.7.0 — состав и границы

База спецификаций: BEHAVIOR-0.3, `main` `fa3aec539055cafdf520d558b0e97537dcf9435b`.
Это **работающее исследовательское ядро**, а не объявление полной реализации спецификаций.
Профиль мира: `headless-research-1s`; баланс `balance-cpp-0.7.0-test1`.
Формулы — игровой баланс; результаты не являются физиологическим прогнозом.

**72 теста C++ этого выпуска не совпадают с 72 будущими приёмками BEHAVIOR-0.3.**
Часть C++-тестов проверяет отдельные функции, часть — взаимодействующий мир. Матрица выше
не позволяет трактовать наличие класса как завершённость всего соответствующего механизма.

## Эпизоды и информация

Результат отдыха/сна/общения берётся из пережитого изменения, а не фиксированной награды.
Приобретение порции изменяет инвентарь, но не становится опытом насыщения тела.
Для приобретения еды планировщик использует обученное начальное представление о знакомой
последовательности «получить порцию → съесть», а не ложное наблюдение уже полученных калорий.
Известное отсутствие еды не становится подтверждённым наличием после таймера: допускается
новый осмотр. Журнал `unpermitted_takes` не передаётся свидетелям как готовый моральный вердикт.

Тело исполнителя не передаётся Planner: его единственный вход — PersonalView. При этом
проектор профиля намеренно упрощён, поэтому тест равных личных входов доказывает границу API,
а не полное соответствие восприятия спецификации.

## Воспроизводимость и ограничения хранения

Seed стабилен для фиксированных версий генератора/каталога; semantic ID в первом C++ API — ASCII,
поэтому NFC для этих ключей тривиально. Произвольные естественно-языковые ключи не принимаются.
Хеш состояния воспроизводится в одной сборке; межплатформенная побитовая эквивалентность
libm не заявлена. Изменение баланса/формата требует нового идентификатора версии.

Холодное хранилище и уплотнение подтверждённых эпизодов пока отсутствуют. Списки обработанных
событий сохраняются и растут со временем; нельзя удалять их ради скорости и терять однократность.
Предел загрузки файла 256 MiB и ограничения вложенных коллекций — технический защитный предел,
не модель забывания. Windows/MSVC-сборка не запускалась; ошибку замены существующего save на
платформе без поддерживаемого rename нельзя обходить удалением старого файла.
