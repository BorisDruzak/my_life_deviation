# Приёмка ядра мира
## WORLD-0.4

**Статус всех IT-сценариев ниже: не выполнялись, потому что полный исполнитель мира ещё не реализован.** Это требования к будущим тестам, не отчёт об успехе симуляции.

Арифметические и статические проверки reference_math/check_spec имеют иной объём: они проверяют отдельные выражения, границы и ссылки каталога. Их результаты приведены в документе 07.

## 1. Правила запуска

Каждый тест создаёт новый мир фиксированного профиля и seed. Неуказанные бытовые данные берутся из явно записанной фикстуры, а не генерируются по времени компьютера. В testing_controller можно задать выбор действий непосредственно: это проверка мира, не автономного планировщика.

Сравниваются поля X, журнал, локальные View и отсутствие запрещённых эффектов. Для времени/денег/ID — точное равенство; для чисел формул — tolerance. Лог показывает причину каждого ожидаемого отклонения.

## 2. Длительный прогон

После IT01–IT40 запускается 7 игровых суток без графики на фиксированной бытовой конфигурации. Снабжение магазинов и фонд зарплат заданы явно; нехватка ресурсов не исправляется скрытым восстановлением. Проверяются диапазоны шкал, денежный баланс, уникальность предметов, отсутствие утечек согласий, рост памяти и размер журнала.

Такой прогон сначала использует сценарные/простые контроллеры, затем подключённый планировщик. Нагрузочные размеры 6, 50, 200, 1000 акторов измеряются отдельно; в спецификации нет гарантии времени исполнения.

## 3. Метаморфические проверки

Поменять скрытую черту без изменения команды и условий — физический контракт не меняется, кроме явно опубликованного внутреннего побуждения/интереса. Поменять знания — физическая возможность не меняется, но меняется допустимость гипотез/последующих решений контроллера. Поменять детализацию графики — никакой физический результат не меняется. Поменять порядок обхода акторов — сохраняется установленный арбитраж и итог.

## 4. Критерий готовности

Ядро соответствует этой редакции после выполнения IT-тестов, инвариантов и повторяемого сохранения. Игровой баланс и интерес профайлинга требуют дополнительных опытов с игроками и не следуют из соответствия мира.
