# Реестр границ и миграция к WORLD-0.4

## 1. Что изменилось по отношению к математической редакции 0.3

Редакция 0.3 смешивала законы исполнения, оценку полезности, прогноз и маленький экспериментальный каталог. WORLD-0.4 отделяет **авторитетную динамику мира**. Её нельзя механически соединить со старым планировщиком без обновления его модели последствий.

| Область | В WORLD-0.4 |
|---|---|
| Формула выбора плана | Вне ядра мира; ему не нужен Q, чтобы исполнить допустимую команду |
| Потребности | Сохранены единицы и базовые расходы четырёх шкал; N05 формально задана в отдельном взрослом абстрактном модуле |
| Дополнительная нагрузка | Убрано второе списание N02 за движение/спорт; введена отдельная физическая усталость F |
| Здоровье | Определены восстановление, истощение, неспособность и терминальное состояние как условная игровая модель |
| Социальное удовлетворение | Добавлены нормированное внимание группы, напряжение и повторение; не умножается на число партнёров |
| Рост привязанности | Используется ограниченный экспоненциальный прирост; совместимость основана на известных признаках |
| Благосостояние | Скользящее сглаживание за игровое время; не среднее «за сессию» |
| Интересы и навыки | Определены контролируемые формулы обучения, выключенные в baseline |
| Положительная обратная связь побуждения | Интенсивность фиксирована; удовольствие/еда сами не создают новые опасные свойства |
| Страх | Только оценённая известная угроза; ядро не выдаёт скрытую вероятность разоблачения |
| Сознательная ложь | Метка намерения закрыта; слушатель строит вывод только по доступным основаниям |
| Согласование | Подписи конкретной версии, самостоятельное решение Б, реальные присутствие и участие |
| Время | Один точный конвейер, контрольный отзыв отдельно от обычного действия |
| Фоновый режим | Те же законы и история; ускорение только после теста эквивалентности |

## 2. Кто может изменять данные

| Данные | Разрешённый писатель |
|---|---|
| Текущие шкалы потребностей | W07 и явные эффекты зарегистрированных действий |
| Физическая усталость/здоровье | W08; авторизованный контракт опасности/травмы, если включён |
| Стресс, злость, уверенность | W11/W18 по времени и доступным основаниям |
| Черты личности, базовые пороги, интенсивность побуждения | Только инициализация/явная миграция профиля; не обычный тик |
| Интересы/навыки | Genesis и включённый W09 |
| Собственность/держатель/размещение | Только W13/W16 в коммите или сохраняемом job |
| Денежные балансы | Только атомарные операции W12, зарегистрированные внешние источники |
| Подпись/отзыв | Сам участник соответствующей версии; проверяет W15 |
| Доверие/привязанность | W14/W18; не произвольная команда собеседника |
| Сведения NPC | W17/W18, собственная память совершённых действий |
| Гипотезы | Локальный интерпретатор/контроллер с доступными основаниями, не копирование hidden truth |
| Реальный журнал событий | Только коммит ядра |
| Отладочная причинность | Запись принятого действия и его переданного reason_ref; наблюдателям не выдаётся |

## 3. Обязательные различия

**Сытость и запас пищи.** Первая — внутреннее состояние, второе — реальные предметы. Одна не подменяет другую.

**Усталость и необходимость сна.** Физическая нагрузка и недостаток сна имеют разные поля, связанную, но не дублирующую динамику.

**Намерение и событие.** Планы можно отменять; прошлые события нельзя редактировать вслед за планом.

**Событие и сведение.** Реальная передача не означает знания всех присутствующих; сообщение о передаче не означает, что она была.

**Привязанность и доверие.** Можно сохранять сильную привязанность при низком доверии; они не сворачиваются в один статус.

**Согласие и ожидание согласия.** Прогноз А не является решением Б.

**Право и физическая возможность.** Отсутствие разрешения не заставляет открытый предмет исчезнуть, но запрещает контракт разрешённого взятия.

**Норма и физический ограничитель.** Моральная цена используется контроллером; предел несущей способности и недоступность из-за физического состояния проверяются миром.

**Корреляция и закон.** Совместная настройка при генерации не означает, что изменение одного поля немедленно перепишет все другие.

## 4. Профили и коэффициенты

`baseline` подходит для проверки причинности без постепенной перестройки характера/интересов. В нём всё равно работают здоровье, усталость, время, деньги, предметы, отношения, знание и обязательства. Изменение состояния возможно; постоянные черты остаются постоянными.

`extended` включает опубликованные формулы обучения и абстрактный взрослый модуль N05. Ни одна из них не должна влиять на NPC, для которого соответствующая возможность явно выключена.

Реестр `world_parameters_v04.json` — единый набор стартовых коэффициентов. Из него можно породить индивидуальные overrides, но они должны быть валидированы и записаны в genesis. Реестр не содержит готового интерпретатора формул. При противоречии текста и JSON реализация должна остановить подготовку профиля; нельзя молча выбирать случайную версию.

## 5. Необходимые дальнейшие инженерные работы

Данная спецификация задаёт поведение будущего кода, но не содержит полного исполнителя мира, арбитра ресурсов, базы локальных знаний или контроллера. Следующий шаг реализации — сначала функции законов и одношаговый исполнитель с транзакциями, затем тестовые сценарии документа 05. Планировщик можно подключить после того, как одинаковая поданная последовательность команд даёт объяснимый воспроизводимый результат.

Задача баланса отличается от реализации законов. После тестов допускаются другие коэффициенты, однако в каждом опыте версия и профиль фиксированы. Отсутствие ошибок арифметики не доказывает, что социальные паттерны интересны игроку или что система масштабируется до тысячи жителей.
