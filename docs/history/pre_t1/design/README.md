# Схемы проекта

В этом каталоге сохранены исходные концептуальные схемы и их переработанные версии.

- `drawio/СИмуляция.drawio` — ранняя исходная схема.
- `drawio/СИмуляция(1).drawio` — более поздняя пользовательская версия.
- `drawio/Симуляция_НПС_обновленная.drawio` — переработанная архитектурная схема с разделением данных, выбора, совместных действий и экспериментального ядра.
- `Симуляция_НПС_описание_изменений.md` — пояснения к переработанной схеме.
- `simulation_drawio_source_review.md` — извлечённое текстовое содержимое схемы для поиска и анализа.
- `Симуляция_НПС_совместные_действия.png` — превью одного из листов.

Схемы — проектный контекст. При конфликте с `docs/spec/WORLD_0.5.md` действующая спецификация имеет приоритет.
