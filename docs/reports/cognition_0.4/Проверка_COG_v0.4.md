# Фактическая проверка COG-0.4

Дата: 2026-09-11. Профиль: `cog-0.4-test-1`. База документации `fa3aec539055cafdf520d558b0e97537dcf9435b`. Это проверка нового алгоритмического комплекта, не прогон C++0.7.

## Состав

Три нормативных документа: когнитивный контур, CPU-планировщик и таблица поправок. Отдельный C++20-эталон: 5 заголовков, 2 исполняемых файла тестов/примеров, CMake и загружаемый при конфигурации профиль. Добавлена ссылка в индексе механик. Старые версии спецификаций сохранены.

Исходная схема drawio и архив BEHAVIOR-0.3 прочитаны. В новом тексте отделены положения исходников, решения переписки и новые предложенные формулы. Проверенный Git blob исходного индекса механик: `dcc8c4034c69e4a6d69f86bdbaeef629da72ef2c` — совпал с локальными байтами базы.

Результаты/логические времена совпали в соответствующих сравнениях. Это не тест многопоточного полного игрового мира.

## Обнаружено и исправлено при подготовке

1. **Повтор ID свидетельства мог содержать другое значение.** Первоначально fusion молча выбирал одну запись. Новая проверка S19 сначала упала, затем добавлено отклонение несогласованного payload.
2. **Одна версия кандидата внимания могла менять содержание.** Изначально равная revision разрешала перезапись приоритета. A17 сначала упала; теперь повтор допустим только с тем же payload, обновление требует новой версии.
3. **Число в текстовом примере стыда уточнено по исполняемой формуле.** Для 0.455 и τ=8 с, Δ=8 с правильное значение 0.28761485, не ранняя округлённая запись документа.
4. **Переполнение аварийных кандидатов уточнено явной срочностью.** Поле urgency и A18 подтверждают приоритет срочности при >32 авариях, включая допустимое вытеснение менее срочного фокуса.

Это ошибки нового эталона/документа, НЕ ошибки, обнаруженные в многодневной симуляции населения. Журнал `05_regression_red.txt`: 66 прошли, 2 упали. После исправления и дополнительной проверки: `19_final_named_tests.txt`, 69 прошли, 0 упали.

Первый `00_preimplementation_compile.txt` показывает отсутствие ещё не написанного заголовка. Это проверка инфраструктурного отсутствия реализации, НЕ доказательство корректного поведенческого TDD для всех функций. Для двух регрессий выше есть реальный цикл неуспеха и исправления.

## Не проверено и не заявляется

Не изменены C++-исходники мира. Не запускались населённый когнитивный мир, работа/стройка с реальным многонедельным выполнением, полный социальный протокол, эксперимент появления девиаций, физиологическая валидность, все 16 новых интеграционных приёмок, полный рост памяти или реальное ускорение проекта на i5/UE5.

Copy/resume scheduler — копирование объекта в одном процессе, не файловый restore движка. Отдельные формулы и очереди не доказывают реалистичность общества и эквивалентность всего полного контура.

Изменения подготовлены файлами и patch; в этом обращении публикация/слияние в GitHub не выполнялись. Последний прочитанный main указан выше; новый код эталона не выдаётся за опубликованный коммит.

## Воспроизведение

```sh
cmake -S "Документация/Проверки/cognition_0_4" -B build-cog -DCMAKE_BUILD_TYPE=Release
cmake --build build-cog -j2
ctest --test-dir build-cog --output-on-failure --no-tests=error
./build-cog/contract_tests
./build-cog/examples
```

В архив входят исходники, нормативная база, исходная схема и реальные журналы команд. Итоговая упаковка дополнительно проверяется после распаковки; результаты этой проверки находятся в `verification/packaging_check.txt`.
