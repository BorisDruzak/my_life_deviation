# C++ 0.6 Primary Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the active WORLD-0.5.1-t1 executable path with the supplied C++ 0.6.0-lab1 implementation while preserving 0.5.1-t1 as a non-built legacy snapshot.

**Architecture:** The active root builds the `mld` library and `mld_sim` CLI. Existing NPC source, build configuration, gameplay data, vendored Boost and historical CI move as one self-contained `legacy/world_0.5.1-t1` snapshot. Documentation is versioned by status: 0.6/BEHAVIOR-0.3 is current, 0.5.1 remains historical.

**Tech Stack:** CMake 3.16+, C++20 standard library, CTest, Python standard library, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-cpp-0.6-primary-migration-design.md`
