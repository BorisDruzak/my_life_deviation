> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Promote the verified RECOVERY 0.13 C++ simulation to the active repository layout without losing SELF 0.12 or any existing documentation.

- Import only files that pass the 586-entry archive `SOURCE_MANIFEST.json` byte and SHA-256 validation.
- Do not apply `RECOVERY_0.13_from_SELF01_0.12.patch`.
- Preserve active SELF 0.12 under `legacy/cpp_0.12/`; do not delete historical documents.
- Keep active engine code headless and deterministic with Body / Cognition / World boundaries.
- Preserve raw delivery materials and evidence under `provenance/incoming/recovery_0.13/`.

- Do not claim native C++ verification unless CMake and a compiler actually run.
