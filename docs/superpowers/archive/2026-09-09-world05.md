# WORLD-0.5: план реализации

**Цель:** автономный исполнитель WORLD-0.4 с исправленной спецификацией, консольным стендом и проверяемой границей знания.
**Архитектура:** типизированное состояние C++20; Boost.JSON используется только для представлений/настроек/сохранения и параметров команд. Мир не имеет доступа к UI, реальному времени или сети. Контроллер получает только локальную проекцию.
**Спецификация:** `docs/reference/01_Спецификация_законов_мира.md`; изменения публикуются в `docs/spec/WORLD_0.5.md` и `docs/spec/ERRATA.md`.
**Исполнение:** последовательно в отдельном каталоге, затем чистая повторная сборка и тесты.

## Единицы поставки
1. [x] Чистая математика, SHA-256 и проверяемая сериализация (`math.*`, `json.*`, `tests/math_tests.cpp`). Сначала тесты контрольных значений, включая 64.2 для полной порции, 45.96 для семи минут, SHA-256("abc").
2. [x] Типы, загрузка и валидация (`model.*`, `config.*`, `validation.*`). Проверки диапазонов, ссылок, денег, контейнерных циклов, версии.
3. [x] Минутный исполнитель, резервы, предметы, дорога, работа и постоянные jobs (`world.*`, `physical.*`, `actions.*`, `economy.*`). Проверить отмену, гонку двух покупок, оплату 37/60, возврат в срок, остановку/возобновление работы.
4. [x] Предложения, версии, самостоятельная текущая готовность, сообщения, наблюдения, отношения (`social.*`, `knowledge.*`). Отказ не штрафует; цифровая доставка не читает; приватные поля не выходят в View; для совместного старта нужны команды всех участников одной границы.
5. [x] Снимки/повтор/инварианты и все A01–A32 (`persistence.*`, `tests/world_tests.cpp`). Сохранение активного действия и очередей; несовместимая конфигурация отвергается.
6. [x] Консольный интерфейс, простая автономная бытовая политика и сценарии (`app/main.cpp`, `controller.*`, `examples/`). Контроллер НЕ является свободным HTN/GOAP; отдельно показать независимый отказ и перезапланирование получения инструмента.
7. [x] Карта IT01–IT40 с явными частичными границами, метаморфические проверки, длительный прогон, GCC/Clang и sanitizers. Сохранять реальные логи; не приравнивать арифметические проверки к интеграционным.
8. [x] README на русском, исправленная нормативная документация, инструкции Linux/Windows, описание границ, архив без каталога сборки.

## Неизменяемые требования
- Целочисленное игровое время, деньги и кванты материалов; double только для опубликованных шкал.
- Общий закон для всех персонажей. Нет особого доступа у "подозреваемого".
- Владение != хранение; сообщение != прочтение; предложение != согласие; подпись != готовность сейчас.
- Прогноз работает на локальной копии и не расходует мировой источник случайности.
- Ни обычная скука, ни возраст/пол не создают опасное побуждение.
- Не публиковать архив как готовую коммерческую игру или полный универсальный планировщик.
