# Механики НПС: актуальные документы

## Внутренняя симуляция человека

[Внутренняя симуляция человека v0.1](Внутренняя_симуляция_человека_v0.1.md) — отдельная предлагаемая математическая спецификация тела, ощущений, эмоций, когнитивных возможностей, внимания и переключения внимания. Содержит формулы, стартовые коэффициенты, временные масштабы, численные примеры, контракты сохранения и 24 приёмочных сценария будущей реализации.

Для следующей реализации конкретные формулы внутреннего механизма берутся из этого документа. Его раздел 21 перечисляет уточняемые положения v0.2.1. Старые обобщённые штрафы и новые коэффициенты нельзя применять одновременно к одному показателю. Это спецификация, не заявление о готовом C++-ядре или окончательно утверждённом балансе.

## Субъективная модель, мышление и обучение

[Обучение, свойства и внутренние расчёты НПС v0.2.1](Обучение_свойства_и_внутренние_расчеты_НПС_v0.2.1.md) — базовая архитектурная концепция: истина мира, восприятие, активный контекст, мысли, субъективные прогнозы, причинные объяснения, обучение и изменение свойств. Исходный файл сохранён без перезаписи.

[Модель личности и выбора действий v0.1](Модель_личности_и_выбора_действий_v0.1.md) — общие свойства личности, раздельные моральные нормы, ограниченная рациональность и выбор знакомых сценариев.

[Оптимизация симуляции и UE5 v0.1](../Оптимизация/Оптимизация_симуляции_и_UE5_v0.1.md) — событийное мышление и распределение вычислительной нагрузки. Укрупнение времени требует соблюдения причинности и проверки относительно опорного расчёта.

## Численная проверка спецификации

[Расчётный скрипт](../Проверки/Проверка_формул_внутренней_симуляции.py) содержит 27 проверок отдельных формул и граничных случаев; при подготовке документа все 27 прошли. Скрипт использует стандартную библиотеку Python и не является реализацией внутреннего механизма или интеграционным тестом игры.

Запуск из корня репозитория:

```sh
python "Документация/Проверки/Проверка_формул_внутренней_симуляции.py"
```

Версии обучения v0.1 и v0.2 сохранены как история концепции. Наличие документации не означает наличия полного собираемого ядра: состав исходников проверяется отдельно перед реализацией.
