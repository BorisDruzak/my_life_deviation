# Механики НПС: актуальные документы

## Текущая спецификация внутренней симуляции — 0.2.0

[Внутренняя симуляция человека v0.2](Внутренняя_симуляция_человека_v0.2.md) — актуальная редакция уточнений: разделённые ассоциативное и причинное обучение, субъективная приятность независимо от новизны, разреженная матрица приобретённых эффектов, ограничения роста связей и математическая глубина знаний темы.

**Состав спецификации 0.2.0:** v0.2 плюс перечисленные в её разделе 1 неизменённые части [v0.1](Внутренняя_симуляция_человека_v0.1.md). В v0.1 остаются формулы тела, ощущений, когнитивных ограничений, периферического обнаружения и переключения внимания. Заменённые формулы обучения и досуга из v0.1 повторно не применяются. Это редакция математической спецификации для будущего C++, не готовое ядро и не окончательно утверждённый игровой баланс.

Половое влечение, его накопительная или контекстная динамика имеют статус **«требует решения»**. Туалет и гигиена исключены по запросу пользователя. Объединение причин одной эмоции пока сохраняет максимум; насыщаемое объединение описано только как возможное развитие.

## Субъективная модель, мышление и обучение

[Обучение, свойства и внутренние расчёты НПС v0.2.1](Обучение_свойства_и_внутренние_расчеты_НПС_v0.2.1.md) — базовая архитектурная концепция: истина мира, восприятие, активный контекст, мысли, субъективные прогнозы, причинные объяснения, обучение и изменение свойств. Исходный файл сохранён без перезаписи; конкретные уточнения внутреннего механизма берутся из редакции 0.2.0 выше.

[Модель личности и выбора действий v0.1](Модель_личности_и_выбора_действий_v0.1.md) — общие свойства личности, раздельные моральные нормы, ограниченная рациональность и выбор знакомых сценариев.

[Оптимизация симуляции и UE5 v0.1](../Оптимизация/Оптимизация_симуляции_и_UE5_v0.1.md) — событийное мышление и распределение вычислительной нагрузки. Укрупнение времени требует соблюдения причинности и проверки относительно опорного расчёта.

## Проверки формул

[Проверки редакции v0.2](../Проверки/Проверка_уточнений_внутренней_симуляции_v0.2.py): 49 численных и контрактных проверок. При подготовке редакции все 49 прошли. Включены обучение без причинного мышления, приятное знакомое занятие без новизны, поканальность, ограничение новых/общих связей, запрет причинного вывода из неизвестного отсутствия и ограничение профессионального рассуждения знаниями.

```sh
python "Документация/Проверки/Проверка_уточнений_внутренней_симуляции_v0.2.py"
```

[Старый расчётный скрипт v0.1](../Проверки/Проверка_формул_внутренней_симуляции.py) содержит 27 проверок старой редакции и сохранён для истории. Его прохождение не является проверкой нового обучения v0.2.

Оба скрипта используют стандартную библиотеку Python. Это локальные эталонные расчёты, не интеграционные тесты игры, производительности, миграций или UE5. Успешные проверки формул не означают завершения реализации НПС.

Исторические версии документов сохранены. Перед реализацией отдельно проверяется состав исходников, а не предполагается наличие собираемого C++-ядра по одной документации.
