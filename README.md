# My Life Deviation

Проект автономной цифровой симуляции NPC для детективной игры. Базовая реализация: NPC World / WORLD-0.5, C++20, без графики, Unreal и LLM.

Общие правила для всех персонажей; индивидуальное поведение формируется знаниями, фактами, порогами, весами и свойствами NPC. Сначала проверяем гипотезы на ограниченном числовом стенде, затем интегрируем в игру.

## Первичный импорт

Репозиторий инициализирован для переноса ранее подготовленного комплекта исходников, тестов, математических спецификаций и draw.io. Это начальная запись контекста, не подтверждение завершения импорта. Актуальный README с командами сборки будет установлен вместе с исходниками.
