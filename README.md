# my_life_deviation

Experimental NPC simulation repository.

## Спецификации и статус

Точка входа: [актуальные механики и приоритет документов](Документация/Механики/README.md).

[SEM-0.1: предметы, понятия, действия и социальные контракты](Документация/Механики/Предметы_понятия_действия_и_социальные_контракты_v0.1.md) фиксирует границу между объективным исполнением и субъективным знанием НПС, общий механизм обмена и согласование с внутренней моделью v0.2.

[SEM-PERF-0.1: производительность](Документация/Оптимизация/Производительность_семантического_контура_v0.1.md) содержит расчётные нагрузки, ограничения реализации и план измерений. Приведённые микросекунды являются предположениями, не результатом бенчмарка.

Репозиторий содержит архитектурные документы и отдельные расчётные проверки. Наличие спецификации не означает наличия полного собираемого C++-ядра или подтверждённой производительности в Unreal Engine.
