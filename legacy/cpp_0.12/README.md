# SELF 0.12 legacy engine

This directory preserves the active C++ SELF 0.12 implementation that was
replaced by RECOVERY 0.13 on 2026-09-13. It is historical source, not the
current build entrypoint.

The preserved build root is `legacy/cpp_0.12/CMakeLists.txt`. It owns the
matching `engine/`, `apps/`, cognition reference, and historical workflows.
Use the repository-root `CMakeLists.txt` for the active release.
