# Внешние компоненты

`third_party/boost` — необходимые заголовки Boost 1.83.0, главным образом Boost.JSON и его зависимости. Оригинальные copyright notices сохранены. Лицензия: `third_party/BOOST_LICENSE_1_0.txt` (Boost Software License 1.0). Заголовки не модифицировались.

`tools/vendor_boost.py` фиксирует способ первоначального получения замыкания заголовков из установленного Boost; для обычной сборки запускать его не нужно. Установка в другую среду не должна автоматически перевендоривать другую версию.

Основные исходники, тесты, примеры и документация проекта подготовлены для пользователя. Лицензия Boost распространяется на Boost, а не автоматически задаёт режим лицензирования собственных исходников проекта. Перед публичной публикацией владелец проекта должен выбрать его лицензию.
