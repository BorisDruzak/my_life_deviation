# Журналы проверки COMMUNITY-0.10

FINAL_VERIFICATION.json связывает окончательную сборку, результаты и SHA256 логов.
Номерные 34/36 — полный Release CTest; 38 — выбранные ASan/UBSan; 41 — все именованные C++-случаи; 40 — анализатор Python.
Остальные файлы — ход TDD/диагностики. Даже если ранний файл содержит final в имени, он не подменяет окончательный протокол. Падающие тесты в red-логах ожидаемы и отражают состояние до исправления.
Проверки баланса выводятся отдельно в reports/community10/RESULTS.md и могут не проходить при успешном CTest.
