# План NORM-MEMORY-0.1

Это пакет проектирования, **не новый патч C++**.

## Читать в таком порядке

1. `NORM_MEMORY_0_1_SPEC_RU.md` — цели, основания, формулы, ограничения и принятые решения.
2. `NORM_MEMORY_0_1_IMPLEMENTATION_PLAN_RU.md` — 12 этапов S0–S11 с путями, API, регрессиями и Definition of Done.
3. `NORM_MEMORY_0_1_TEST_MATRIX.json` — 87 будущих приёмочных сценариев с given/when/expected; все имеют status planned_not_run_against_cpp.
4. `NORM_MEMORY_0_1_PROFILE.json` — предлагаемый численный профиль; C++ 0.13 его ещё не читает.
5. `reference/` — исполняемая Python-проверка выбранных формул и известного-source revision, не модель поселения.

Запуск численных проверок:

```sh
cd reference
python -m unittest -v test_norm_math_reference
```

В `evidence/` находятся аудит источников и свежий результат reference-проверок. Предварительный `REFERENCE_RED.log` относится только к отсутствовавшему ещё reference-модулю при создании проверок; это не доказательство воспроизведения бага C++.

## База

Проверенный GitHub main уже содержит RECOVERY 0.13: `36dc381b121e552fd4c961d8a2a90fd48a2a09d0`. Для изучения использованы его README/navigation/CMake/фрагмент mind.cpp/МОР-0.2 и распакованный архив 0.13. Полная локальная копия main не получена из-за DNS. При исполнении обязательна S0-проверка всей базы. Source C++ в этом задании не изменён; C++-тесты и недельные миры нового нормативного механизма не запускались.

## Главные изменения относительно устного наброска

Не сводить мораль к страху наказания. Сохранить четыре разных содержания: практика, приписываемое одобрение, последствия и личное принятие. Нормативное напряжение создаёт тему внимания, но не вторую награду/цену. Молчание не равно одобрению. Известный общий источник и скрытый мировой root — разные данные. SelfModel не переписывается и не получает фиктивный опыт.
