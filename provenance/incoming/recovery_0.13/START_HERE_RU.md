# RECOVERY 0.13 — проверенная поставка

Исходники находятся в `source/`; это новая реализация поверх приложенного SELF01 0.12, не патч к реорганизованному GitHub main. Удалённый репозиторий не изменён.

1. Распакуйте архив и собирайте из `source/` по его README.md.
2. Для обновления существующей чистой архивной 0.12 используйте `RECOVERY_0.13_from_SELF01_0.12.patch` из её каталога source. Выполните сначала `git apply --check`. Не применяйте патч поверх произвольной версии.
3. Новые правила и ограничения: SPEC_RU.md. Фактические результаты: REPORT_RU.md и RESULTS.json.
4. SOURCE_MANIFEST.json даёт SHA-256 всех 586 файлов исходников. DELIVERY.json содержит применение патча, сравнение файлов, свежую сборку извлечённых исходников и коды тестов.

## Доказательства

Окончательные: evidence/verified_release, verified_sanitizers, verified_week_42/7/101, delivery_clean. Все три недельных мира используют тот же life_sim, что получен новой сборкой из извлечённых исходников.

Baseline — контроль исходной 0.12. Папки с red, diagnostics, hunger_capture и acceptance_week_7 — намеренно сохранённые промежуточные ошибки и их диагностика, НЕ итоговые результаты. В частности, критический голод промежуточного seed7 исправлен и отсутствует в verified_week_7.

Весь исходный код вошёл в архив. Из диагностических артефактов не включены компилированные исполняемые файлы, промежуточный save и большие полные трассы; точные исключения и хеши включённых журналов перечислены в DELIVERY.json. Исходники диагностических постановок и их компактные результаты сохранены. Команды execution.json содержат исходные абсолютные пути среды проверки — адаптируйте пути к месту распаковки.

Прежние документы и результаты внутри source относятся к истории 0.10/0.11/0.12. Новая проверка ими не подменяется.

## Границы

Подробности — в SPEC_RU.md и REPORT_RU.md. Это исследовательский профиль: одна розница с внешним снабжением, текстовый (не голосовой) телефон, передача известных ограниченных процедур, добровольная денежная помощь (не кредит). Все четыре свободные покупки — базовая одежда; демонстративные дорогие покупки и денежная помощь в недельных мирах не возникли. Причинный механизм помощи проверен отдельным автономным парным тестом.
