# my_life_deviation — 0.11.0-experimental.1

Автономная C++20-симуляция NPC без LLM и без зависимости от игрового движка.

В этой итерации добавлен **отдельный экспериментальный профиль**: сохраняемые цели и известные процедуры, поиск компании и знакомство, договорённости о встрече, добровольная партнёрская близость, разговор поверх совместимой деятельности, рабочий контракт и общий рост ставок от вклада коллектива.

**Начать с [отчёта о проверках и свободных симуляциях](reports/life11/REPORT_RU.md)** и [исполняемой спецификации 0.11](docs/LIFE_0_11_SPEC_RU.md). Границы реализации и нерешённые проблемы перечислены явно. Это не завершённая реализация всех ОТН/BEHAVIOR-спецификаций и не готовый модуль Unreal Engine.

## Сборка и тестирование

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j 4
ctest --test-dir build -C Release --output-on-failure
```

Для генераторов Windows с несколькими конфигурациями исполняемый файл обычно находится в `build/Release/life_sim.exe`; для одноконфигурационной сборки Linux — `build/life_sim`.

```sh
# Новый профиль: 16 персонажей, 7 игровых дней
./build/life_sim --life-projects --population 16 --days 7 --seed 42 \
  --summary summary.json --life-state life.json --community-state community.json \
  --actors actors.csv --save week.save

# Продолжить существующий мир; не передавать настройку нового профиля при --load
./build/life_sim --load week.save --days 1 --summary next_day.json

# Контроль того же исполняемого файла без новых целей/рабочего контура
./build/life_sim --community --population 16 --days 7 --seed 42

# Только отключить прогноз насыщения индивидуального способа
./build/life_sim --life-projects --no-satiation-forecast --population 16 --days 7 --seed 42
```

Флаг `--life-projects` сам включает исходный community-контент. Не нужно одновременно указывать `--community`. Сохранения 0.10 имеют иной формат и новым ядром намеренно не открываются.

## Воспроизвести сравнительную серию

Python 3.10+ нужен только для организации и анализа испытаний, не для ядра.

```sh
python tools/validate_life11.py --binary build/life_sim --population 16 --days 7 \
  --seeds 42 7 101 --jobs 1 --output reports/life11/reproduced
```

`--jobs 1` подходит для измерения последовательного времени; несколько процессов ускоряют проверку, но их wall time нельзя трактовать как чистый benchmark. В каждом каталоге сохраняются команда, возврат процесса, JSON-отчёты и таблица персонажей. Невыживший NPC в ресурсно обеспеченном нормальном сценарии приводит к неуспеху приёмочной серии.

## Исходная база и публикация

Комплект основан на переданном пользователем архиве C++ 0.10.0, а не выдаёт документационный `main` GitHub за исполняемый исходник. Метаданные — `SOURCE_VERSION.json`. Изменения подготовлены в отдельной локальной ветке `feature/life-projects-0.11`; удалённый `main` не изменён.
