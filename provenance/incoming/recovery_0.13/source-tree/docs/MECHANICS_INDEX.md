# Карта всех механик и спецификаций

Этот файл — точка входа. **Нормативная идея, локальный эталон и интегрированный механизм — разные статусы.** Для фактического покрытия 0.10 см. [матрицу реализации](IMPLEMENTATION_STATUS.md).

## Порядок чтения

[Описание исполняемого COMMUNITY-0.10](COMMUNITY_0_10_SPEC.md) уточняет новый исследовательский профиль, но не отменяет неперенесённые требования.
[Эмпирический эталон](EMPIRICAL_REFERENCE_0_10.md) отделяет измерения от предлагаемых чисел.
Базовые регламенты читаются по BEHAVIOR-0.3 и таблице замен COG. Старые и новые формулы не суммируются.

## Связь с кодом

| Область | Код |
|---|---|
| Тело/численные реакции | `src/life/numeric.cpp` |
| Личные знания, Q/W/C и варианты | `src/life/mind.cpp` |
| Субъективные оценки и мысли | `src/life/cognition.cpp`, `src/life/cognitive_world.cpp` |
| Время мира и физическое продвижение | `src/life/world.cpp` |
| Исполнение действий/ресурсы | `src/life/executor.cpp` |
| Начальное население | `src/life/generation.cpp` |
| Социальные нормы/предметы/контакты | `src/life/social.cpp`, `src/life/social_world.cpp` |
| Информация/забывание/мнение | `src/life/community.cpp` |
| Новые события/работа/досуг/поселение | `src/life/community_world.cpp` |
| Файлы и инварианты | `src/life/persistence.cpp`, `src/life/validation.cpp` |
| Рабочие потоки | `src/life/worker.cpp` |
| Новые тесты | `tests/test_community.cpp`, `tests/test_community_analysis.py` |

Полные исходные формулы COG находятся также в `Документация/Проверки/cognition_0_4`; этот эталон не заменяет интеграционные тесты мира. Спецификации механик, ещё не реализованных полностью (например общий причинный анализ), сохранены, а не удалены ради заявления о полноте.
