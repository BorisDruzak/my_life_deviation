# C++ 0.7: исполняемый исследовательский стенд

**Цель:** получить сохраняемый, собираемый headless-мир по BEHAVIOR-0.3, а не объявить все спецификации реализованными по наличию формул.
**База:** main fa3aec539055cafdf520d558b0e97537dcf9435b; дерево ab14f5411e7ca544f17a38ce566fe937af6913c6.
**Спецификация:** ../../Документация/Механики/Редакция_поведения_v0.3.md.
**Архитектура:** C++20 / стандартная библиотека / CMake. Numeric-модуль не знает мир; Planner принимает только PersonalView; World проверяет и исполняет команды. Изменяемые данные отделены от производных индексов. Исследовательский профиль явно перечисляет отличия от полной спецификации.

## Обязательные ограничения
Seed и версии в манифесте; все активные жители взрослые; нет LLM и UE5; нет фактического штрафования; еда не списывает деньги; конечное моральное сопротивление; один основной слот действия; общее ограничение мыслей; отдельно Q/C/W; новые W только со следующего интервала; отсутствие сведения не равно ложности.

## Последовательность
1. [ ] `include/life/numeric.hpp`, `src/life/numeric.cpp`, `tests/test_numeric.cpp`: девять состояний тела, ощущения, когнитивная матрица, эмоции, насыщение, D/R/V. Сначала тест `body_loses_water`: после 3600 секунд покоя воды меньше; при нулевом времени битово прежнее значение. Прямой тест отрицательного времени и NaN.
2. [ ] `include/life/seed.hpp`, `src/life/seed.cpp`: SHA-256 и BIO-ключи; тесты известных SHA-256 и сравнение ключа с Python-эталоном, независимость стадий.
3. [ ] `include/life/mind.hpp`, `src/life/mind.cpp`, `tests/test_mind.cpp`: личные знания, Q/C/W, доверие, мораль, согласие, Planner. Тест: два одинаковых PersonalView -> одинаковые команды независимо от скрытого мира. Проверки нулевого наблюдения, повторов, границ и шестого канала.
4. [ ] `include/life/world.hpp`, `src/life/world.cpp`, `tests/test_world.cpp`: seed-граф/родство/история, пути, ресурсы, субъективный выбор и исполнение. Проверка 100 seed и сохранения ресурсов. Индексный и полный поиск должны давать одинаковые результаты.
5. [ ] `include/life/archive.hpp`, `src/life/persistence.cpp`: версия/ограничения/checksum; побитовая проверка продолжения после save/load. Исторический `src/persistence.cpp` сохраняется и не включается в новую цель.
6. [ ] `src/life/main.cpp`, CMake/CI, `tools/validate.py`: CLI, CSV/JSONL, повторяемые сценарии, локальные unit/integration/differential и sanitizer-проверки. Ненулевой код при ошибке, отсутствие CMake не считается успехом.
7. [ ] `docs/COVERAGE_0.7.md`, `reports/RESULTS_0.7.md`: фактические результаты, исправленные ошибки, непокрытые механики и ограничения измерений; публикация только проверенных файлов.

## Команды проверки
```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
python tools/validate.py --binary build/life_sim --out reports/runs
```
Критерии: проверки реально возвращают 0; в нормальном сценарии все основные способы исполняются; нет отрицательных ресурсов, скрытого штрафования и расхождения indexed/reference. Ограничения баланса не прячутся изменением спецификации. Полная готовность каждого механизма устанавливается отдельно в COVERAGE, не выводится из количества тестов.
