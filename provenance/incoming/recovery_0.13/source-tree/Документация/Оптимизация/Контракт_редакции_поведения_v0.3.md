# Оптимизация и сохранение редакции поведения 0.3

**Версия:** 0.3.0. **ID:** OPT-0.3. **Дата:** 2026-09-11. Дополнение [SAFE-OPT-0.1](Семантически_точная_оптимизация_v0.1.md) для [BEHAVIOR-0.3](../Механики/Редакция_поведения_v0.3.md). Ни одна формула ниже не является замером быстродействия.

## 1. Три разные вещи

Точная оптимизация меняет только цену вычисления прежних правил. Ограниченный контекст, привычная процедура и 60-секундное условие повторной попытки — правила персонажа, а не способы экономить CPU незаметно. Упрощение физики/восприятия/памяти или отключение институтов — явно именованный профиль модели, не доказанная эквивалентность полному миру.

В стандартном профиле все активные НПС подчиняются одним правилам. Низкая загрузка, расстояние до игрока или число worker-потоков не изменяют их интеллект, мотивы, доступные события или прошлое мира.

## 2. Новые зависимости и пределы

| Объект | Хранимый источник | Точная область инвалидирования |
|---|---|---|
| Социальный посев | Seed, версия, семантический каталог, канонический порядок | Изменение входов генератора, не косметических имён |
| Зависимость А→Б | Личные цели, известные вклады и альтернативы | Только изменённые собственные основания А |
| Локальная репутация | Собственные источники, интерпретации и тематические результаты | Полученное сообщение/переоценка А, не скрытый поступок Б |
| Контекст влечения | Реальные экспозиции, исходный профиль и шестой канал W | Замеченное/вспомненное содержание, версии свойств и времени |
| D и R | Значение, время, параметры, применённые s | Разрез по изменению параметра и событию удовлетворения |
| V и ощущения | D/R/T/I, времена, пороги/гистерезис | Каждая значимая граница входов/пересечение порога |
| Знакомая процедура | Шаг, личные условия, известная карта, результат | Собственное наблюдение/мысль, а не истинная доступность |

Общие пределы не суммируются между модулями: 32 кандидата внимания; до 4 тем×16 записей памяти; контекст 2–12; до 8 кандидатов мысли; до 32 ID известных правил в очереди; операции 4+floor(28×текущая скорость обработки). Новый канал меняет число рассмотренных пар W с 80 на **96**. До четырёх новых пар за эпизод и 512 приобретённых пар/адресных свойств остаются общими.

До 128 горячих социальных записей на НПС не означает удалять остальные. Холодный индекс должен возвращать тот же нормативный отбор, что полный эталонный поиск. Нельзя искусственно ограничить поиск первыми попавшимися записями и назвать это точным ускорением.

## 3. События и время

Сохраняются опорные единицы и шаг внутренней v0.1. Прошедшее время разворачивается до следующей логической границы; физические воздействия продвигаются до неё, затем применяются разовые эффекты, проекции, ощущения, доступные операции, обучение завершённых эпизодов и команды будущего интервала. Все некоммутативные действия имеют стабильный порядок. Результат не изменяет своё прошлое.

D и R допускают ленивый точный переход при неизменных коэффициентах и отсутствии неучтённого s. V связан с меняющимися D/R и не получает автоматического права на длинный шаг. Переход через порог ощущения должен создать событие на его нормативном времени. Пока условия аналитического перескока не доказаны, используется обычный эталонный путь.

Для одинакового времени порядок конфликтующих физических операций определяется начальным временем заявки, затем стабильным ключом логической команды. Низкий ID не должен давать постоянную привилегию: при одинаковом времени допускается ключ от seed, номера события конкуренции и ID, вычисленный один раз и сохранённый. Порядок завершения worker-задач не используется. RNG и распределение прав не переигрываются при повторной доставке.

Модель параллельности: снимок → чистое чтение/расчёт → команды → стабильная сортировка → авторитетная фиксация. Секретное изменение мира может менять объективный кэш исполнителя, но не субъективный кэш контроллера. Технические причины отклонения не превращаются в полное игровое знание.

## 4. Графы и память

Генеалогия — разреженные адресные записи с неактивными родственниками; запрет O(N²) относится к штатному построению и обновлению, не к маленькому эталонному тесту. Знакомства строятся по группам и соединению компонент. Ссылки на эпизоды общие, персональные проекции раздельны. При холодном хранении сохраняются необходимые основания и возможность переоценки; сжатие не должно уничтожать идентификатор первоначального вклада.

Техническая дедупликация защищает однократность эффекта. Группировка доказательств в рассуждении использует известное НПС происхождение. Проверка истинного общего источника слуха допустима разработчику, но не может влиять на решение как бесплатное знание.

Рост истории, Q/C/W, социальных записей и очередей измеряется раздельно. Ограничение вывода на экран не ограничивает нормативную память. Выключение расширенного лога не меняет RNG, события и результаты.

## 5. Сохранение

Версия пакета состояния 0.3.0 включает версию каталогов/конфигурации/профиля, seed и ключи генератора, локальные образы, родство/историю, собственные нормы, источники репутации, доступность происхождения, D/R/V, шестой W, процессы, бюджеты, резервы, частичные результаты и очередь событий. Новые поля нельзя восстановить «разумным значением» без отмеченной миграции.

Сохраняемый чистый кэш не является нормативным. Восстановление с ним и без него должно совпадать. Физические передачи, события удовлетворения и обучающие окна имеют уникальные ключи. Снимок фиксируется только на согласованной границе либо сохраняет прогресс всех незавершённых стадий явно.

## 6. Критерий приёмки оптимизации

| ID | Сравнение |
|---|---|
| ОПТ3-01 | Эталонный полный поиск и индекс дают один нормативный набор |
| ОПТ3-02 | Холодный/тёплый кэш не меняет решения |
| ОПТ3-03 | Скрытые изменения не инвалидируют субъективное знание |
| ОПТ3-04 | 1/2/4 worker-потока дают одинаковые события и состояния |
| ОПТ3-05 | 30/144 кадров/с не меняют логические завершения |
| ОПТ3-06 | D/R между неизменными границами совпадают с разбиением интервала |
| ОПТ3-07 | Связанный V/ощущения сравниваются на каждой значимой границе |
| ОПТ3-08 | Restore до/после s/сообщения/обучения не повторяет эффект |
| ОПТ3-09 | Посев не использует порядок hash-map/общий изменяемый RNG |
| ОПТ3-10 | Отключение подробного лога не меняет смысловой хеш |

Для вещественных локальных формул тестовый допуск 1e−12 абсолютный; он **не разрешает разные дискретные решения или время порогового события**. Межплатформенный bitwise-детерминизм математической библиотеки не заявляется без отдельной проверки. Для посева канонические входы/целочисленные выборки задаются БИО-0.1.

Замер включает число реально обработанных событий, операций, аллокаций, пары W, размеры памяти и время. Нельзя заявлять ускорение после уменьшения числа событий/потребностей. Масштабирование N=128/512/1024 выполняется только после поведенческой проверки; эти значения пока план тестирования.
