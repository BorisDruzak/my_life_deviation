# COMMUNITY-0.10: восстановление и завершение этапа

База: реально распакованный архив C++0.9.0; новых исходников незавершённого этапа в выдаче не обнаружено. Работа идёт в отдельной локальной ветке community-0.10. Старые отчёты остаются историческими, их цифры не являются результатами нового кода.

## Задачи и проверяемые границы

1. Воспроизвести дефект бюджета: tests/test_community.cpp::budget_four_can_choose. Проверить достижимость привычного действия при 4 операциях; текущий случай проваливается до исправления.
2. community.hpp / community.cpp: сведения, происхождение, частичное забывание, тематические мнения и конечная цена конфиденциальности. Тесты обращаются к реальным типам, не мокам. Никакого World* в оценке темы.
3. community_world.cpp + social_world.cpp: реальные сообщения внутри бесед; замороженный состав слышащих в начале реплики; доставка через оплаченный SocialObserve; наблюдение реальных завершений действий. Фикстуры не назначают ответы.
4. Четыре объявления работы, Study и шесть видов досуга; известная цена отдельно от оплаты. Платёж в начале услуги не повторяется; внешние зарплаты учтены ledger. Квалификация требует конкретного содержания.
5. Внешность, индивидуальные предпочтения и три конечных нормы романтики; восприятие не раскрывает неизвестное родство. Норма не меняет согласие адресата физическим образом.
6. Полное сериализуемое состояние, диагностика тем/мнений/денег/бюджета времени; CTest, ASan/UBSan, повтор архива, пары reference/workers/logging/save.
7. Несколько суточных и недельных прогонов с новым профилем; стресс и контрфактические сцены. Незакрытые механики и несоответствие эмпирическим ориентирам публикуются явно.

## Команды

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
./build/life_tests community
ctest --test-dir build --output-on-failure --no-tests=error
```

Новые правила — версия профиля community-0.10; отсутствие эквивалентности прежнему поведению 0.9 не называется ошибкой оптимизации. Индекс и reference используют один новый профиль. Базовые сценарии 0.9 сохраняются для регрессий. Никакая численная цель реального населения не применяется как принудительная квота поведения.
