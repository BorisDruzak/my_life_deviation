## Сборка и обязательные тесты

Проверенная среда: Linux, GCC 14.2 / Clang 17, C++20, CMake >=3.20, Python >=3.10 и стандартная библиотека. Сторонних C++-библиотек/LLM/сети при запуске нет. Windows/MSVC и UE5 не проверены.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure --no-tests=error
python tests/test_community_analysis.py
```

## Симуляция и измерения

```sh
./build/life_sim --community --population 16 --seed 42 --days 1 \
  --summary day.json --community-state community.json --actors actors.csv \
  --thoughts thoughts.jsonl --trace actions.jsonl --trace-actor 1

python tools/run_community.py --binary build/life_sim --out my-run --seed 42 --population 16 --days 7
python tools/analyze_community.py my-run --out my-audit.json
./build/community_scenarios my-social-fixtures
```

`--community` обязателен для нового профиля. Без него работают прежние сценарии. Платёж за досуг/учёбу/еду реален; зарплата — явно внешний источник денег. `--reference` отключает пространственное ускорение; `--workers 4` меняет CPU, не модельную скорость мыслей. `--save FILE`, `--load FILE` сохраняют/продолжают текущее состояние. Миграции 0.9 и промежуточного 0.10-test1 нет.

Дневной runner фиксирует SHA256 бинарника и не смешивает сборки. После изменения кода/параметров используйте новую папку результатов. Сохранения создаются runner автоматически; команды в журнале могут содержать исходные абсолютные пути среды, но приведённые здесь команды переносимы.

Логи мыслей — описание структурированных операций, не свободный текст управляющей LLM. Полные журналы быстро растут; выбирайте --trace-actor. Отключение журнала не меняет поведение.

## Профили и границы

Настройки экономики/новой памяти скомпилированы; docs/community_profile_0_10.json только документирует их. 16 жителей — маленькое плотное окружение, не репрезентативное общество. Быстрое обучение профессиям, лишние разговоры и критические интервалы в обеспеченных мирах отмечены как проблемы. Нельзя по числу прошедших контрактных тестов объявлять симуляцию научно валидированной.

Архив содержит весь исходный комплект спецификаций BEHAVIOR/SEM/COG, их эталоны и исторические отчёты. Исторические результаты не относятся автоматически к новому выпуску. Новые результаты лежат в reports/community10/release и verification/community10.
