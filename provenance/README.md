# Provenance

`my_life_deviation_git_ready_0.5.1-t1.zip` is the canonical source archive
for the restored C++20 implementation. Its internal `SHA256SUMS` manifest was
checked directly against all 719 ZIP entries before migration.

`my_life_deviation_REPO_READY.zip` is a verified pre-T1 archive. Only its
unique historical product and design documents are retained. Its C++ code is
not part of this working tree.

Archive checksums prove file integrity only. They do not replace a fresh local
CMake build and CTest run.
