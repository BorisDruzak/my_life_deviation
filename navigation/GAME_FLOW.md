# Связь игры с ядром

```text
docs/rules/behavior_0.3 + game/profiles/behavior_0.3
                         │
                         ▼
apps/simulate/mld_sim ──► engine/include/mld (публичный API)
                         │
                         ▼
engine/src/core ──► engine/src/simulation ──► engine/src/autonomy
                         │                            │
                         └──────────── проверки и отчёты ────────────┘
```

BEHAVIOR-0.3 задаёт материалы и порядок редакций; профиль содержит параметры
лабораторного запуска. `mld_sim` создаёт мир, запускает генерацию и
детерминированную симуляцию, затем печатает JSON-результат. Ядро не читает
архивные отчёты как входные данные.

Проверочные скрипты в `docs/verification/behavior_0.3/` фиксируют численные
контракты документации. Они и отчёты из `docs/reports/cpp_0.6/` не расширяют
возможности `mld` сверх ограниченного лабораторного профиля.

WORLD-0.5.1-t1 расположен в `legacy/` и `docs/history/` исключительно для
сравнения; активные CMake и CI его не собирают.
