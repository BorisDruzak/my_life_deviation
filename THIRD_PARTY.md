# Внешние компоненты

Проект использует Boost.JSON 1.83.0 и транзитивно необходимые заголовки Boost.

В Git не коммитируются сотни неизменённых upstream-заголовков. `CMakeLists.txt` сначала использует установленный Boost >= 1.83.0; если подходящей версии нет, CMake получает официальный архив Boost 1.83.0 с `archives.boost.io` и проверяет SHA-256:

`6478edfe2f3305127cffe8caf73ea0176c53769f4bf1585be237eb30798c3b8e`

Boost распространяется по Boost Software License 1.0. Исходный T1 delivery ZIP, из которого опубликован этот репозиторий, содержал локальное замыкание необходимых заголовков; собственный код и его поведение при этой нормализации зависимостей не изменялись.

`tools/vendor_boost.py` оставлен как вспомогательный исторический инструмент для формирования локального header closure из установленного Boost 1.83. Для обычной сборки он не требуется.
